# أنجز — منصة طلابية عربية

موقع ثابت متعدد الصفحات يجمع الملخصات، آراء الطلاب في المواد، إنشاء الجدول الدراسي، ومجتمعات الكليات. الواجهة عربية بالكامل ومتجاوبة، والبيانات وتسجيل الدخول يعملان عبر Firebase.

## ما الجديد في هذه النسخة

- هوية بصرية عالمية موحّدة بالأزرق البنفسجي مع ألوان مساعدة للخدمات.
- واجهة فاتحة وداكنة تراعي إعداد الجهاز وتحفظ اختيار المستخدم.
- تحسين كامل للهواتف والأجهزة اللوحية وسطح المكتب.
- خط عربي حديث، أيقونة للموقع، وبيانات وصفية أفضل لمحركات البحث.
- إصلاح نموذج آراء الطلاب وإضافة أربعة محاور تقييم واضحة.
- تقييم الملخصات وحفظ المفضلة مع إرسال بلاغات خاصة بالروابط المعطلة أو المحتوى غير المناسب.
- حفظ الجدول الدراسي تلقائيًا في المتصفح مع فحص التعارضات.
- صفحة للمسار الأكاديمي تشمل محاكي المعدل، حاسبة التخرج، إنذار الغياب، والتحقق من تعارض التسجيل.
- تحسين التباين، حالات التركيز، وتقليل الحركة لمن يفضّل ذلك.
- حماية أفضل من إدخال HTML داخل عناصر الجدول الدراسي.

## تشغيل الموقع محليًا

لا تفتح الصفحات بالنقر المباشر على الملفات لأن JavaScript Modules وFirebase يحتاجان خادمًا محليًا. من داخل مجلد المشروع شغّل أي خادم ملفات ثابت، مثل:

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## إعداد Firebase

إعدادات المشروع موجودة في `firebase-config.js` وقواعد قاعدة البيانات في `firestore.rules`.

قبل النشر:

1. انشر قواعد Firestore من Firebase Console أو Firebase CLI.
2. فعّل Google ضمن Authentication → Sign-in method.
3. أضف نطاق GitHub Pages، مثل `username.github.io`، إلى Authentication → Settings → Authorized domains.
4. اختبر تسجيل الدخول وإضافة ملخص ورأي ومنشور كلية بعد النشر.

> مفتاح Firebase الظاهر في واجهة الويب ليس كلمة مرور بحد ذاته؛ الحماية الفعلية تعتمد على قواعد Firestore وAuthorized domains. لا تضع مفاتيح خوادم أو حسابات خدمة داخل هذا المستودع.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا أو افتح المستودع الحالي.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. من Settings → Pages اختر Deploy from a branch.
4. اختر فرع `main` والمجلد `/ (root)` ثم احفظ.
5. بعد ظهور رابط الموقع، أضف نطاقه إلى Firebase Authorized domains.

لا يحتاج الموقع إلى عملية Build أو إلى `node_modules`.

## الملفات الرئيسية

- `index.html`: الصفحة الرئيسية.
- `summaries.html`: الملخصات والبحث والإضافة.
- `lectures.html`: آراء الطلاب والتقييمات.
- `exams.html` و`schedule.js`: منشئ الجدول وفحص التعارضات.
- `academic.html` و`academic.js`: أدوات المعدل والتخرج والغياب والتسجيل.
- `colleges.html` و`college.html`: مجتمعات الكليات.
- `profile.html`: الملف الشخصي ومشاركات المستخدم.
- `style.css`: نظام التصميم المتجاوب والوضع الداكن.
- `app.js`: تسجيل الدخول وFirestore ووظائف الصفحات.
- `ROADMAP.md`: اقتراحات التطوير التالية مرتبة حسب الأولوية.
